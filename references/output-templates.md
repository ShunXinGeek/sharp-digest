# 输出模板库

## 全局约定

- 所有模板开头必须附**分级图例块**——读者先看懂标签再看内容。
- 位置引用格式：¶/§/页/Table/Appendix/Annex/函号，随文档类型；一篇之内格式统一。
- 语言：用户提问的语言；专有名词、定义术语、条款号、案名保留原文。

## 图例块模板

```
**分级图例**：【律/据】=条款/判例确立或已证数据；【定】=作者明确判断；【倾】=作者倾向性看法（"seems"级，非结论）；【主】=当事方主张（非既证事实）；【开】=开放问题。¶xx=原文段落号。
```

## 模板 A：六段式完整深读（L3 默认）

```
# <文档标题> 归纳总结

（分级图例块）
（一行文档状态声明：working draft / 定稿 / 征求意见稿 + 日期 + 作者角色定位）

## 一、三行结论
1. <最强结论，带标签与出处>
2. <次强结论，带标签与出处>
3. <障碍/风险/下一步一句话，带标签与出处>

## 二、一页速览
<表格：关键当事方、日期、金额、编号、程序状态等硬信息>

## 三、实体矩阵（核心交付物）
<按 doc-type-routing.md 对应类型的列定义；每个单元格的观点带标签与位置引用>

## 四、横切议题
<贯穿多个实体的方法论/框架层问题；写清它如何改变各实体的解读>

## 五、观点分级清单
### 明确判断【定】
### 倾向性看法【倾】（"seems"级，非结论）
### 开放问题【开】

## 六、行动与待办
<文档给出的下一步 + 各方待办 + 程序节点>

---
**验证说明**：<分级执行情况；引用格式；硬信息落位 N/M；已知缺口>
```

**写作要点**：
- 三行结论做**可替换性检验**：这三句若能原封不动用在任何一份同类文档的总结里，说明提炼不足，重写。
- 矩阵单元格不许写"有争议/存在分歧"这类空话——必须写明**主张是什么、依据是什么、谁主张**。
- 观点分级清单要**穷尽**作者的实质观点；漏掉文档明确讨论过的观点 = 覆盖失败。

### 变体：L1 一页纸速览
三行结论 + 速览表 + "如需深入读什么"三行指引。适合管理层传阅；用户点名"一页纸"时用此模板。

### 变体：L4 跨文档附加段
六段式之后追加：
- **跨文件对齐表**：`议题 | 文件A观点(位置) | 文件B观点(位置) | 是否一致/如何演进`
- **关联文件地图**：`文件号 | 日期 | 状态 | 与本案关系`

## 模板 D：传阅用浓缩版（抽取式，非分析式）

**触发词**：用户要"浓缩版 / 精简版 / 给同事传阅 / 保持原话"。此时**不做**分析性改写：

- 只删不改：保留作者原话与原顺序，删除冗余段落；
- 每个保留段落带位置引用，便于对照原文；
- 不新增任何解释、不改变任何限定词；
- 结尾附**删减清单**（删了哪些节、为什么）。

设计来源：doc-compression 理念——**总结改变措辞，浓缩保留措辞**；两者用途不同，用错场景会误导读者（浓缩版看似分析总结，实为节选）。

## 自检清单（Phase 4 用）

1. 三行结论在最前？
2. 逐条比对：无升格（倾向→定论）？无混装（主张→事实）？
3. 抽查 5 条位置引用，回原文核实。
4. 硬信息底账全部落位？
5. 图例块在开头？文档状态已声明？
6. 模板顺序未乱？无"按页顺述"残段？
7. 数值保真（无"约"化）？专有名词未译？

## 验证说明模板

```
**验证说明**：本总结共标记【定】X 条、【倾】Y 条、【开】Z 条，倾向性观点均未升格；
位置引用采用 ¶/§/Table/附录 格式，抽查 N 条无误；硬信息底账 M 项全部落位；
已知缺口：<如 附录 B 数据未逐页核对 / 关联文件未随附，未做交叉核对>。
```
