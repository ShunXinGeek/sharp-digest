# 证据分级体系（tier system）

## 为什么必须分级

真实案例：一份 75 页的 DRAd 争议报告（working draft）中，裁决顾问通篇使用 "it seems to me / perceptions / may perhaps"——这是其"促进和解、不作裁决"角色的法律姿态。一份把这些表述升格为"DRAd 认定/裁决"的总结，不仅是模糊，而是**事实性歪曲**：它替作者作出了他刻意保留的决定。反过来，把作者明确引用的判例规则（如 *Walter Lilly* 的并发延误规则）降格为"报告可能有如下观点"，同样是失真。

分级的意义：让读者一眼分清**规则的分量、作者承诺的分量、各方立场的分量、未知事项的边界**。

## 五级标签

| 标签 | 定义 | 判定信号 | 常见错误 |
|---|---|---|---|
| 【律/据】Established | 已确立的规则 / 已证数据 / 有出处引用 | 条款号、现行有效判例、实测数据、附审计编号的财务数、文献引用 | 把未生效草案当生效；把已推翻的旧判例当现行法 |
| 【定】Firm | 作者明确承诺的判断 | 无对冲词的直接断言；"I find / I conclude / 兹认定" | 把带对冲词的句子误读为定论 |
| 【倾】Hedged | 作者的倾向 / 初步看法 | seems to me、appears、perceptions、初步、倾向于、似乎；中文"可能"用于观点时 | **升格**——最常见的致命错误 |
| 【主】Claim | 利益方主张 / 待检验论证 | 当事方函件、答辩、营销材料、未经对质或验证的断言 | 把主张混成"报告说的"事实 |
| 【开】Open | 开放问题 / 待查明 | 明示 pending、待审计、待技术评估、TBD、事实未决 | 把开放问题当已决事项转述 |

## 分领域的【律/据】与【主】具体化

### 争议/法律文书
- 【律/据】：生效合同条款（标注条号）；现行判例规则（案名+裁判要旨）；程序事实（会议日期、函件编号）；已核实数量。
- 【主】：雇主/承包商/律师函中的全部主张；专家报告中的单方结论（除非已被采纳）。
- 【倾】：裁决者/DRAd/DAB 的 seems/perceptions/初步意见。
- 位置引用格式：¶段落号 / §条款号 / Table X / Appendix X / Annexe X / 信函编号（如 J489-MWP3-153）/ 判例名+报告引用。

### 学术论文
- 【律/据】：实验结果（含基线对比、消融、显著性）；已确立的背景结论（带引文）。
- 【定】：作者明确陈述的发现（"X improves Y by Z%"）。
- 【倾】：Discussion/Limitation 中的推测、机制性解释。
- 【主】：novelty 声明、与相关工作的对比主张（需对照实际 delta 核验后再定级）。
- 【开】：Future work、未验证假设。
- 位置引用：§章节号 / Table X / Fig. X。

### 商业/技术报告
- 【律/据】：审计后财务数据、实测性能、标准符合性证书。
- 【主】：被评估方/供应商主张（尤其未审计的"预计成本"）。
- 【倾】：顾问倾向（"评估组倾向于认为"）。
- 【开】：待尽调/待专项审计事项。
- 位置引用：§/页码/附件编号。

### 政策/咨询文件
- 【律/据】：强制性条文（应当/必须/不得——注意与"鼓励/倡导/试行"区分）。
- 【倾】：征求意见稿中的方向性表述。
- 【主】：各反馈方意见。
- 【开】：公开征求意见的开放问题。
- 位置引用：章节/条款号。

## 操作规则

1. **禁止升格**。示例（真实案例）：
   - 原文（DRAd 报告 ¶30.8）："…it seems that it should be taken that the EPD has no comment on them."
   - ✗ 错误输出："DRAd 认定 EPD 无意见。"
   - ✓ 正确输出："【倾】EPD 28 天内未表态→就合同目的应视为无意见（¶30.7-30.8）。"
2. **禁止降格**。把明确的判例规则写成"可能存在如下观点"同样失真。示例：*Walter Lilly* 的并发延误规则是【律/据】，不是【倾】。
3. **说话者归属**：主张必须挂主体——"承包商主张…"，不许写成"报告指出…"。
4. **位置引用**：每条观点可回溯，格式随文档类型（见上）。
5. **数值保真**：精确数字+单位原样保留（HK$60,438,602；75 天；551 天），不得"约"化；区间如实（2-3 周）。
6. **引语 vs 转述**：直接引语加引号+位置；转述不得增删限定词（"any special circumstance of any kind whatsoever" 不能转成"特殊情况"）。

## 输出中的分级呈现

- 输出开头给**图例块**：本总结使用的标签一览 + 一句话定义。
- **观点分级清单**按【定】【倾】【开】三档分列（【律/据】融入正文与速查表；【主】进入实体矩阵的各方主张栏）。
- 矩阵单元格内用标签前缀（如"【主】承包商主张…"）。
